# Hospital Management Tool

A desktop-based hospital management application built with **Python, Tkinter, and MySQL**.

## Overview

The Hospital Management Tool is a Python desktop application designed to manage hospital-related data through a graphical user interface.

The application uses **Tkinter** for the user interface and **MySQL** for database storage and management, providing a practical example of connecting a Python desktop application with a relational database.

## Tech Stack

- Python
- Tkinter
- MySQL
- MySQL Workbench

## Requirements

Before running the application, make sure the following are installed:

- Python 3
- MySQL Server
- MySQL Workbench

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/techykaif/Hospital-Management-Tool.git
```

### 2. Navigate to the project directory

```bash
cd Hospital-Management-Tool
```

### 3. Configure MySQL

Make sure your MySQL server is running and configure the database connection in the application according to your local MySQL credentials and database setup.

### 4. Run the application

```bash
python hospitalmanagement.py
```
